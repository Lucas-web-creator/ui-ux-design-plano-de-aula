# 🎨 Formação Completa em UI/UX Design — Planejamento & Framework Curricular

Este repositório contém a documentação completa, a estrutura curricular e o material de apresentação do plano de estudos para a **Formação em UI/UX Design**. 

O projeto foi estruturado com base em uma metodologia de **aprendizagem progressiva baseada em projetos**, focando na resolução de problemas reais de produto digital — conectando pesquisa, arquitetura, design visual, sistemas e implementação frontend.

---

## 📌 Visão Geral do Projeto

A formação foi desenhada para ir além do uso de ferramentas de interface. O objetivo central é desenvolver o pensamento crítico, a capacidade analítica e o rigor técnico necessários para atuar em todo o ecossistema de produtos digitais.
